# 机器直连传动

模拟室和四档单方块工厂的左右两面可接 Create 传动杆。同一根轴贯穿机器，输入侧和输出侧属于同一传动网络。流体工厂从控制器的正面接入，控制器应朝向结构外侧。手持 Create 传动杆对准接轴面时，会看到半透明的放置预览，右键将杆放到预览的位置。两类机器仍通过 Mekanism 的能量容器、槽位和面配置处理物品。

机器的方块继承 Mekanism 方块并实现 Create 的 `IRotate`。方块实体仍是 Mekanism tile，内部持有一个同坐标的 Create `KineticBlockEntity`。Mixin 仅在 Create 查找传动邻居、验证动力源和统计应力时返回内部轴。机器保存并同步轴的状态，Create 负责传递转速、计算负载及处理过载。

有待加工的配方时，机器才向 Create 网络申报应力。Create 用每 RPM 的影响值乘以转速计算 SU，因此内部轴会把机器所需的总 SU 换算成对应的影响值。网络停转或过载时暂停加工与耗电。模拟室和四档工厂的加工速度随转速变化，网络容量达到总负载的 1.5 倍时翻倍。流体工厂沿用速度核心的加工倍率。关闭 `enableStressRequirement` 后可按正常速度加工。

旧版试玩放置的通用传动接口保留原有方块 ID。沿轴向对齐时，它可以继续作为传动杆使用，右键查看网络的应力与转速。
